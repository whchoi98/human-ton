# 검증 기록

검증일: **2026-09-13**. 이 기록은 패키지의 동작과 제한된 원고에서의 편집 행동을 확인한 결과다. 사람 독자 선호 조사나 AI 작성 여부 판정 실험은 아니다.

## 설치 도구와 문자열 대조

Python **3.9.25** 환경에서 다음 명령으로 **66개 시험**을 통과했다.

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
```

| 대상 | 시험 수 | 확인 내용 |
| --- | --- | --- |
| 설치 도구 | 37 | 세 설치 경로, 참고 파일 복사, 원본 저장소 없이 사용, 충돌 시 전체 사전 중단, 재실행 시 무변경, 백업·복구, 심볼릭 링크, 공백 포함 경로, 드라이런 |
| 문자열 대조 | 29 | 수치·단위·날짜·인용·코드·URL·보호 문자열, 중복 누락, 입력 오류, 읽기 전용 동작, 같은 숫자의 대상 교환을 놓치는 한계 |

설치 시 기존 사용자 설정을 수정하지 않고, 전용 스킬 폴더와 Kiro 에이전트 파일만 다뤘다. 설치된 세 사본의 **12개 파일**은 배포 원본과 SHA-256이 일치했다. 재실행 드라이런은 네 설치 대상 모두 `unchanged`를 반환했다.

설치 중 일반 오류의 복구를 시험했지만, 프로세스 강제 종료·시스템 장애·동시 파일 변경을 모두 포괄하는 트랜잭션은 아니다. 문자열 대조는 의미 동등성이나 자연스러움을 검사하지 않는다.

## 스킬 없는 대조군과 스킬 적용

## 실제 CLI 호출

원본 저장소의 경로를 읽지 않아도 실행되도록 임시 프로젝트에 패키지를 복사한 뒤 시험했다.

| 환경 | 확인 범위 |
| --- | --- |
| Codex | 현재 세션의 하위 에이전트가 스킬을 실제로 읽고 위 원고 시험 수행. 제작 도구의 frontmatter 검증 통과. 별도 `codex` 프로세스로 생성한 시험은 아님 |
| Claude Code **2.1.263** | 정상 프로젝트 스킬 탐색으로 `/human-ton`을 호출해 A 원고 윤문. 결과만 반환, 수치·직접 인용 내용·유보 보존 확인 |
| Kiro CLI **2.21.2** | 에이전트 설정 검증, 목록 노출, `--agent human-ton` 실행. `SKILL.md`와 한국어·리듬·장르·예시 파일 읽기 성공, A 원고 윤문 확인 |

최종 사용한 호출 형태:

```text
Claude Code: /human-ton <요청과 원고>
Kiro CLI:   kiro-cli chat --agent human-ton --no-interactive --trust-tools=read,fs_read "<요청과 원고>"
```

실제 결과와 실행별 스킬 해시는 [native-clis.json](../evals/results/native-clis.json)에 있다. Claude는 일반적인 의미 추가 검수 문장을 보강한 뒤 시험했고, Kiro는 구체적인 부사 예시까지 보강한 최종 지침으로 재시험했다.

실행 시험에서 찾아 고친 사항:

1. **Kiro의 도구 누락.** 처음에는 `resources`만 있는 에이전트가 본문을 읽지 못했다. `tools: ["read", "write"]`와 `allowedTools: ["read"]`를 명시한 뒤 실제 파일 읽기를 확인했다.
2. **짧은 부사의 의미 추가.** 원문에 없던 “더”가 추가 행동을 암시한 결과가 있었다. 시간·정도·추가 행동의 대조와 일반적인 예시를 보강했다. 마지막 Kiro 결과에는 그 추가가 없었다.
3. **Claude 검증 환경.** 작업 폴더에 따라 PATH에서 **2.1.197**과 **2.1.263**이 다르게 선택됐다. 실행 파일을 고정해 2.1.263으로 시험했다. `--bare`에서는 명령을 찾지 못했지만 정상 프로젝트 탐색에서는 실행됐다.
4. **빈 검증 결과를 성공 근거로 삼지 않음.** `claude plugin validate`는 해당 호출에서 `contents: []`를 반환했다. 이 종료 코드만으로 스킬 내용을 검증했다고 계산하지 않았다.

## 확인 범위의 한계

이 결과는 소수의 원고와 현재 실행 환경에 한정된다. 다른 모델·장문·장르에서 같은 결과를 보장하지 않는다. 자연스러움은 편집자의 취향과 독자에 따라 달라질 수 있다.

[자동 선택용 입력 12개](../evals/trigger-cases.json)는 향후 회귀 점검을 위해 준비했다. 각 CLI의 **암시적 자동 선택률**을 측정한 결과는 아니다. 위 실행 시험은 스킬을 명시적으로 호출했다.
